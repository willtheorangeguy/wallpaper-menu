Wallpaper Menu adds **Remove this wallpaper** to the Windows 11 desktop context menu. It is designed for a slideshow made from copies of your photos in `Pictures\Wallpapers`.

## Key Features

- Remove the current slideshow photo from the desktop menu.
- Select photos by display in a multi-monitor setup.
- Send wallpaper copies to the Recycle Bin without an app confirmation.
- Install the menu for your Windows account.

## Installation

Download and run **WallpaperMenu-Setup.exe** on Windows 11. [Latest release](https://github.com/willtheorangeguy/wallpaper-menu/releases/latest)

## Usage

1. In **Settings** → **Personalization** → **Background**, choose **Slideshow** and select **Pictures** → **Wallpapers**.
2. Right-click an empty spot on the display showing the photo.
3. Choose **Show more options** → **Remove this wallpaper**. Check the Recycle Bin to verify the photo was removed.
