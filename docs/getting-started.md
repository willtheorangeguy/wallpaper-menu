# Getting started

## Prerequisites

Use a Windows 11 account with a `Wallpapers` folder inside its Pictures folder. Put copies of the photos you want in the slideshow there. To check your Windows version, press **Windows + R**, enter `winver` and check that the dialog identifies Windows 11.

## Install

Download **WallpaperMenu-Setup.exe** from the [latest release](https://github.com/willtheorangeguy/wallpaper-menu/releases/latest) and open it. The installer shows an **Installed** message.

## First run

1. Open **Settings** → **Personalization** → **Background** and select **Slideshow**.
2. Browse to **Pictures** → **Wallpapers** and select that folder. Windows starts showing photos from it.
3. On the display showing a photo you want to remove, right-click an empty area of the desktop.
4. Choose **Show more options** → **Remove this wallpaper**. Open the Recycle Bin to verify the photo is there.

## What just happened

Wallpaper Menu found the current photo for the display under the pointer, moved that file into the Recycle Bin, and asked Windows to advance the slideshow.
