# Troubleshooting

## Remove this wallpaper is missing

Right-click an empty spot on the desktop and open **Show more options**. If the command is missing there, run the installer again from the Windows account where you use the slideshow. See [Installation](./installation.md).

## The current wallpaper is not an available photo

Check the slideshow album in **Settings** → **Personalization** → **Background**. Set it to the account's **Pictures** → **Wallpapers** folder. If you already removed the current file, use **Next desktop background** to move past the cached image.

## The photo stays on screen after removal

Check the Recycle Bin for the file. Windows may still show its cached copy until the slideshow advances. Right-click the desktop and choose **Next desktop background**. On multiple displays, Windows may advance another display first.

## Windows could not identify the monitor

Open the desktop menu on the display with the unwanted photo and keep the pointer there while selecting **Remove this wallpaper**. Windows matches the pointer to an attached display when the menu command starts.
