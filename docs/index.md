# Wallpaper Menu

Wallpaper Menu adds **Remove this wallpaper** to the Windows 11 desktop context menu. Use it to remove an unwanted picture from a slideshow made from copies of your photos in `Pictures\Wallpapers`.

## Key features

- Remove the picture from the desktop menu without opening File Explorer.
- Choose the picture on a specific display in a multi-monitor setup.
- Send the copy to the Windows Recycle Bin.
- Install the menu for your Windows account.

## Quick start

Download and run [WallpaperMenu-Setup.exe](https://github.com/willtheorangeguy/wallpaper-menu/releases/latest). Set the Windows background to a slideshow from `Pictures\Wallpapers`, then right-click an empty spot on the display showing the picture. Choose **Show more options** → **Remove this wallpaper**. See [Getting started](./getting-started.md) for the full walkthrough.
