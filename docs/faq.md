# FAQ

???+ question "Can I restore a photo I removed?"

    Open the Windows Recycle Bin, find the photo and choose **Restore** while it is still there. Windows puts it back in its original folder.

??? question "What happens to my original photo?"

    The app targets the displayed file inside `Pictures\Wallpapers`. If you copied the photo into that folder from another location, the other copy remains available there.

??? question "Can I use a different folder name?"

    The app looks for a folder named `Wallpapers` inside the Windows Pictures folder for your account. Set that folder as the slideshow source.

??? question "Why did a different monitor advance too?"

    Some Windows versions only accept a request to advance the next scheduled display. In that case the app checks the selected monitor after each advance and stops when that wallpaper changes or it reaches the attempt limit.
